# Uma Skill Simulator

This project is a simulator for skill activation and race mechanics in Uma Musume Pretty Derby.

## Credits & Acknowledgments

This entire project is heavily based on the incredible work by **alpha123**. Most of the core simulation logic, skill data structures, and track data are derived from the following repositories:

*   [uma-tools](https://github.com/alpha123/uma-tools)
*   [uma-skill-tools](https://github.com/alpha123/uma-skill-tools)

A huge thanks to alpha123 for providing the foundation for these tools.

## Features

*   **Race Simulation**: High-fidelity step-by-step race simulation (1/15s precision).
*   **Skill Activation**: Support for complex activation conditions (geographic, rank-based, proximity-based, etc.).
*   **Track Data**: Accurate representations of various race tracks, including corners, straights, and slopes.
*   **Multi-Horse Comparison**: Simulate and compare the performance of different Uma configurations.
